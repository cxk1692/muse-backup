# AI membership reselling shop

Goal ID: goal_02d057f69076
Goal slug: ai-membership-reselling-shop

## Description
Kuai is launching a second-tier AI membership reselling shop that takes no direct top-ups and holds no inventory, using a distributor's distribution code to auto-sync products and fulfil orders. The shop is built on his Sydney VPS with Dujiao-Next, Glock was chosen first for QQ price-priority talks, but the project is paused until customers appear, as the vetted suppliers are only one to three months old.
