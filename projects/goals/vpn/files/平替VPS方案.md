## 买完后的部署（和甲骨文教程同一套，我来执行）
1. 开机选 Ubuntu 24.04（没有就 22.04），记下公网 IP 和 root 密码/密钥
2. SSH 登录 → 跑 kejilion 脚本开 BBR → 重启
3. 跑 233boy 脚本一键装 v2ray → **保存生成的订阅链接（等同密码，不外传）**
4. 如商家有面板防火墙，放行脚本给出的端口
5. 客户端导入订阅，测延迟和连通性
