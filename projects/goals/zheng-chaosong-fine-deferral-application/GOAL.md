# Zheng Chaosong fine deferral application

Goal ID: goal_9680fd18fcba
Goal slug: zheng-chaosong-fine-deferral-application

## Description
Help kuai's family apply in writing to the Shaoyang Shuangqing District Court to defer Zheng Chaosong's ¥30,000 fine, using the court's own 2025 termination-of-enforcement ruling as proof the family cannot currently pay. The case is filed separately for his brother and is not counted as kuai's own matter. The application is drafted; the next steps are filling the four blanks, printing two signed copies, and mailing by EMS, with the village name on the hardship certificate matching its official seal.
