# Company-registered China Mobile SIM cancellation

Goal ID: goal_b5768f65b824
Goal slug: company-registered-china-mobile-sim-cancellation

## Description
Cancel the China Mobile SIM registered in the company's name with kuai's ID as the registered user. Cancellation requires the company's stamped authorisation and an agent carrying company documents to the home-region store, with an objection-based removal or suspension as fallback if the company delays.
