- Viral example kuai flagged 2026-10-30: 何艾伦 @allenhe168 post (2026-10-29 20:18, 1.38M views / 911 replies / 2965 likes): "卧槽，最近出啥事了？据说，惠普，华硕，戴尔，富士康要将生产厂线迁回中国。是有什么大事发生了吗？" Lesson — 极简提问型 works for rumor/wind-direction topics: only 3 short chunks, opens with emotion+question, uses "据说" rumor framing, drops a concrete big-brand list, ends with an open question, author states no conclusion and replies in comments keeping both sides arguing. Information deliberately incomplete so the comment section completes it. Contrast with the story-first format: use story-first for hard news facts, minimal-question for rumors/shifts everyone has a theory about.
