# X Draft Batches

## Check the batch against today first

- List every topic delivered earlier the same day before you write a new batch.

- Compare each candidate topic with that list and treat a close variant of a used topic as the same topic.

- Replace any candidate that repeats a used topic with a fresh topic before you deliver the batch.

- Keep the same day list in your working notes and check the final batch against it one more time before delivery.

## Keep each topic broad and replyable

- Choose topics a stranger can join in one sentence without specialist knowledge.

- Prefer universal subjects such as money, parents, work, holidays and life choices over a narrow event or a precise figure.

- Drop a candidate that needs exact numbers or a narrow event to make sense.

- Rewrite a narrow candidate as a broader question only when the broader version still keeps its point.

## Ground each draft in real discussion

- Search public sources across several platforms before you write the batch.

- Read the actual comments under the relevant posts instead of relying only on a hot list or a news headline.

- Start each draft with one concrete event, person or number from that discussion.

- Avoid stacking precise figures in a draft and end each draft with a pointed question that invites a reply.

## Deliver drafts ready to copy

- Deliver each draft as a separate post in X line break format.

- Keep each draft short and keep numbering, titles and explanations out of the draft body.

- For an interactive discussion batch, write interactive discussion drafts only and leave out pure information posts and pure jokes.

- Treat the parallel abstract funny segment batches as outside this skill and do not apply this section to them.

- Leave posting to the user and do not log into the user account to post a draft.

## Available connectors

- Use `muse.connector_search` to find other connectors and `muse.skill_search` to find related skills.

- If nothing here fits, look on the web for a maintained API or MCP server and set it up with [Custom Connectors and MCPs](/opt/muse/skills/custom-connector-setup/SKILL.md), or build a custom connector.

## Websites

- [X](https://x.com/) for public posts and replies. Carry the candidate topic into `browser.browse` and verify what people are actually arguing about in the replies.

- [Weibo](https://weibo.com/) for public posts and comments. Carry the candidate topic into `browser.browse` and verify the argument in the comments.

- [Baidu Tieba](https://tieba.baidu.com/) for forum discussion. Carry the candidate topic into `browser.browse` and verify what forum users are actually debating.

- [Douyin](https://www.douyin.com/) for short video comments. Carry the candidate topic into `browser.browse` and verify the reaction in the comments.

## Alternatives for better results

- Swap a repeated topic for a fresh universal topic instead of rewording the repeat.

- Ask the user to choose between two close topics when both look strong and neither can be replaced cleanly.

- Reduce the batch size rather than filling it with a narrow or repeated topic.
